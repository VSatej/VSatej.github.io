Neural Compressor Lab is a small project built to understand the end-to-end flow of an audio processing application. It connects a web interface, backend services, and a C++ audio processing component.

The application uses Nuxt 3 for the frontend, Flask for the backend, and C++ to implement the audio compression logic. Users can upload WAV files, adjust compressor parameters such as threshold and ratio, and listen to the processed audio.

Building this project helped me explore PCM audio samples, WAV file handling, digital signal processing, and communication between different software components—from file upload in the browser to sample-level processing and audio playback.

**GitHub:** [View Source Code](https://github.com/VSatej/neural-compressor-lab)

**Technologies:** Nuxt 3, Pytorch, Python, Flask, C++, Digital Signal Processing (DSP), WAV/PCM Audio.
